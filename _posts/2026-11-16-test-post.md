## 代码高亮

```java
public class LightImpl extends Light {

    private final LightsManagerBinderService mService;
    private int mId;

    LightImpl(int id, LightsManagerBinderService service) {
        mId = id;
        mService = service;
    }

    @Override
    public void setBrightness(int brightness, int brightnessMode) {
        mService.setBrightness(mId, brightness, brightnessMode);
    }
}
```

```c
static int lab_open(const char *path)
{
    int fd = open(path, O_RDONLY | O_CLOEXEC);
    if (fd < 0) {

        return -1;
    }
    return fd;
}
```
